# 📚 SQL Online Bookstore Project

This project is based on an Online Bookstore database created using MySQL.

##  Project Overview

The project contains data related to:

-  Books
-  Customers
-  Orders

SQL queries are used to retrieve, analyze, and understand the data from the bookstore database.

##  Technologies Used

- MySQL
- SQL

## 📊 Database Tables

### 1. Books
Contains information about books such as:
- Book ID
- Title
- Author
- Genre
- Price
- Stock

### 2. Customers
Contains information about customers such as:
- Customer ID
- Customer Name
- Email
- Location

### 3. Orders
Contains information about orders such as:
- Order ID
- Customer ID
- Book ID
- Order Date
- Quantity

##  SQL Concepts Used

- SELECT
- WHERE
- ORDER BY
- GROUP BY
- HAVING
- COUNT()
- SUM()
- AVG()
- MIN()
- MAX()
- JOIN
- Aggregate Functions
- Subqueries

##  Project Objectives

- Retrieve useful information from the database
- Analyze customer orders
- Find frequently ordered books
- Analyze sales and book data
- Practice SQL queries and database concepts

##  Learning Outcome

Through this project, I practiced SQL querying, data retrieval, aggregation, and working with relational databases using MySQL.
